# neospark-imagegen-cli-skill

Install the `neospark-imagegen-cli` skill for Claude Code, Codex, and OpenClaw via `npx`.

## Install

```bash
npx neospark-imagegen-cli-skill install
```

Install for a single agent:

```bash
npx neospark-imagegen-cli-skill install --agent claude
```

## Uninstall

```bash
npx neospark-imagegen-cli-skill uninstall
```

## Supported agents

- `claude` → `~/.claude/skills/neospark-imagegen-cli`
- `codex` → `~/.codex/skills/neospark-imagegen-cli`
- `openclaw` → `~/.openclaw/skills/neospark-imagegen-cli`

After installation, restart your agent or reload skills.
